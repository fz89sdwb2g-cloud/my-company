# QA — контроль перед merge

Версія вважається стабільною тільки після проходження цього списку.

## Загальне
- [ ] Сторінка відкривається без порожнього екрану.
- [ ] Навігація між усіма 8 розділами працює.
- [ ] Перезавантаження сторінки не стирає локальні дані.
- [ ] Мобільне відображення не блокує основні дії.

## Оргструктура
- [ ] Відкриваються 5 відділів.
- [ ] Відкриваються кабінети людей/AI.
- [ ] «Редагувати роль» є тільки в кабінеті.
- [ ] Зміна ролі/фото зберігається після reload.

## Власник
- [ ] Місячні показники зберігаються.
- [ ] Середній чек рахується коректно.

## Партнери
- [ ] Додавання майстра.
- [ ] Пошук і фільтри.
- [ ] Картка та історія не губляться після reload.

## Завдання
- [ ] Додавання задачі.
- [ ] Фільтри статусів.
- [ ] Збереження після reload.

## Аналіз ринку
- [ ] Конкуренти.
- [ ] Виробники.
- [ ] Додавання/редагування.
- [ ] Історія цін.
- [ ] Наступна дата перевірки.

## Працівники
- [ ] Старт/кінець зміни.
- [ ] Виробіток і тарифи.
- [ ] Розрахунок зарплати.
- [ ] Щоденний стандарт.
- [ ] Ревізія і фото.
- [ ] Посадова інструкція.
- [ ] Експорт резервної копії.
- [ ] Імпорт резервної копії.

## Дані / хмара
- [ ] Старі localStorage-ключі не перейменовані/не видалені.
- [ ] `myCompanyOrgRoles_v2` входить у backup/cloud data set.
- [ ] На етапі стабілізації логіка cloud sync не змінена.

## Merge gate
- [ ] Порівняно diff тільки з `stabilization-v1-4`.
- [ ] Немає випадкових змін секретів/ключів/підключення.
- [ ] Любомир переглянув тестову версію.
- [ ] Лише після підтвердження дозволено merge.
