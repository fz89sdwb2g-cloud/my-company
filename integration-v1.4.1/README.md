# «Моя компанія + ШІ» — тестова збірка 1.4.1

Основа: передані власником `index.html` і `staff.js`, архів Replit від 02.11.2026.
Готовий файл для відкриття: `dist/index.html` (усі стилі та сценарії всередині).
Вихідні файли збережено поруч. Робочий `index.html` репозиторію не змінюється.

## Зміни
- В одній сторінці зібрані оргструктура, працівник, аналіз ринку, власник, партнери та завдання.
- Відновлені конкуренти, виробники, товари, контакти, перевірки цін, історія, резервна копія/відновлення ринку.
- Працюють завершення/повернення завдань, пошук і фільтри партнерів.
- Панель власника підставляє збережені дані місяця, зокрема нульові значення.
- Дата дня визначається за місцевим часом браузера.
- Додано експорт усіх семи ключів даних одним JSON без їх зміни. Загального імпорту цього формату поки немає; ринок і працівник мають окремі імпорти.
- Дані використовують попередні ключі localStorage; перенесення фактичних робочих даних ще не виконано.
- Робоча хмара Supabase у цій тестовій збірці вимкнена. Для перевірки використовуйте окрему адресу/профіль браузера. При відкритті за адресою робочої програми браузер надасть ті самі локальні дані.

## Перевірено 03.11.2026
`node integration-v1.4.1/tests/integration.cjs` із кореня репозиторію (потрібен jsdom):
10 інтеграційних сценаріїв: навігація восьми розділів, унікальність ID, історія цін і два типи контрагентів, панель власника, статуси завдань, фільтри партнерів, зміна й виробіток, повторне відкриття, захист пошкодженого JSON працівника/ринку, конфлікт і переповнення сховища ринку, збереження інших ключів.
У Chrome через інтерфейс перевірено запуск, створення конкурента й його наявність після перезавантаження; оглянуто сторінку працівника.
Браузерна перевірка виявила відсутність randomUUID на HTTP-адресі тесту: додано сумісний генератор через getRandomValues.

## Межі готовності
Це інтеграційна тестова версія, не завершена операційна система. «Процеси» та «Маркетинг» поки залишаються інформаційними заготовками з вихідного файлу. AI-ролі — описи, автономні AI-агенти не підключені. Повні фінансові розрахунки, операції/винагороди майстрів, синхронізація між пристроями, перевірка на iPhone та перенесення реальних даних потребують окремого етапу.
Захист запису при пошкоджених даних та паралельному редагуванні не уніфікований для всіх розділів; особливо потрібне подальше посилення початкових модулів партнерів/завдань/панелі та захисту від конфліктів у працівнику. Перед робочим запуском — резервна копія й приймання власником.
