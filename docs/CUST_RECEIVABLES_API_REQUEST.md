# Борги КУСТ — частина єдиного завдання

Окреме завдання на борги замінено **[єдиним повним завданням на доступ до бізнес-обліку КУСТ](CUST_FULL_BUSINESS_DATA_ACCESS.md)**, редакція 2 від 14.11.2026.

У ньому зібрані потреби всієї програми «Моя компанія»: борги та погашення, каси/банк, продажі, закупівлі, фізичні запаси, витрати, послуги, комісії, історія, захист персональних даних і критерії приймання. Передавати розробнику потрібно одне основне завдання за посиланням вище.
